## Thread 2 — Worktree vs. new-session distinction, for the upcoming Graphify trial

**What happened:** Cameron asked what the practical difference is between "a new session" and "a separate worktree," having originally proposed the worktree for the Graphify trial without the two being clearly distinguished. Clarified: a session (`session-N` branch) is checked out in the same folder, replaces whatever was there before, and follows the full Session Workflow because it's meant to become part of the repo's history. A worktree is a second folder linked to the same repository that can hold a different branch checked out simultaneously, physically isolating whatever happens there from the main folder.

**Decisions made:** The Graphify trial doesn't need to be a session at all — nothing from it is meant to be committed (`graphify-out/` is gitignored scratch). It will use a plain, throwaway branch (not a `session-N` name) in its own worktree, with no session log and no PR. If the trial leads to a real, keepable decision later (e.g. actually making the robocopy `/XD` fix permanent), that would happen as its own small, ordinary session in the main folder — not inside the worktree.

**Unresolved:** None — refines, rather than reopens, the worktree decision already made in session-41 (Thread 4 of `session-2026-07-13-003.md`).
