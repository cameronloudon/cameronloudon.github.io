## Thread 1 — Fixing generate-provenance.ps1's Three-Times-Confirmed Regression

**What happened:** Cameron asked what a real fix would look like for the bundle-wide `generated:` regression that had now recurred identically across batches 29–31, 32, 33, and 34 (same 46 files each time). Diagnosed precisely: `at:` derives from a file's most recent git commit, correct only until the stamping commit itself becomes that "most recent" touch — after which any later bundle-wide run recomputes `at:` against the stamping commit's own date, not the file's genuinely meaningful edit. Drafted the exact diff (docstring update, an idempotency guard, a new summary-output line) and staged it as a proposal to Cowork rather than building directly, since this is the same shared script she scoped and reviewed when it was originally built.

Cowork's review verified the diagnosis against `attribution-schema.md` §3's own documented `--amend --no-edit` safeguard — confirming the fix complements that design rather than fighting it — hand-traced the parsing regex against real `generated:` values she'd read that same day (including the `wrapper: Person` case), and added a fifth test scenario: a malformed `generated:` line that doesn't match the regex should fall through to a normal recompute (fixing it), not be silently trusted or silently skipped.

**Decisions made:** Applied the diff, then built a synthetic test sandbox (an isolated git repo in the scratchpad, not the real project) and ran all five agreed scenarios before touching any real data: a fresh stamp, an already-current file proven byte-identical via `git status` across an unrelated intervening commit (the actual regression trigger), a legitimate recompute after a real `wrapper:`/`identity:` edit, an unrelated new file added to the same batch not regressing its siblings, and a malformed `generated:` line correctly falling through to a fix on first pass and then staying protected on the next. Then ran the fixed script against the real 554-file `_messages/` bundle — 86 already-stamped files, zero writes, confirmed via `git status`. Committed (`f30e1ae`).

**Unresolved:** None. The regression is demonstrated fixed against both synthetic scenarios and real data, not just reasoned about.
