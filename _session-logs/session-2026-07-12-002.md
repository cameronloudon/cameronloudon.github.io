## Thread 2 — Designing the session-close handshake

**What happened:** Cameron proposed tying the session-close checklist to the moment Claude Code already reliably announces readiness for a PR, rather than to Phase 2 (which fires after merge and can only ever catch a miss one PR late — a limitation already named as unsolvable in the prior day's proposal to Cowork). Iterated the exact wording together across several passes: renamed the initial signal from "ready for the PR" to **"Session-X's DRAFT is ready for consideration to PR"** to remove the ambiguity of it reading as a go-ahead; added explicit handling for "No" / "keep working" (defers the step, re-signals later, does not close it out); added a mandatory **"Please hold while I finalise the session log"** message as the actual forcing mechanism — it converts a step that could be silently skipped into one that has to be spoken and therefore attempted, which the existing permission system already polices reliably; and a final **"Session-X finalised — ready for the PR"** as the only message that actually clears Cameron to create the PR.

**Decisions made:** Five-step handshake agreed in full; Cameron confirmed to apply it as written.
